# Chalax

> 基于纯律（Just Intonation）的二维泛音网格乐器 · 三语界面 · 无需构建

---

## 中文

**Chalax** 是一个纯前端、无构建步骤的 Web 微分音 / 泛音网格应用，基于 **LΛMPLIGHT 的「シャサフ式（Shasavistic）音乐理论」**。它把「维度（dimension）= 素数泛音」可视化为一张二维纯律晶格：每个格子是一个音，点击、拖拽或按键盘即可发声，并可叠加显示音差（逗号比 + 音分）。

### 功能特性

- **二维纯律晶格**：横向 / 纵向各选一个维度（1D–5D 对应素数 2、3、5、7、11），格子音高比 = `横向素数^x × 纵向素数^y`（八度约减）。
- **多种演奏方式**：点击、拖拽、键盘（中间 `asdf` 行为根音行）；长按键盘持续发声。
- **音差显示**：每个音到各维度泛音的音程差，以「逗号比 + 音分」呈现，可按阈值与维度筛选。
- **6 种音源**：正弦波合成器 + 5 种采样（钢琴、拨弦、颤音琴、竖琴、管风琴），并可调整延音。
- **三种亮色依据**：音差（最近维度色）、维度方向（根音白）、频率波长（频率 → 光波长 → 颜色），附饱和度调节。
- **自定义形状（和弦）**：录制一组相对根音的音，选中后一键演奏；可用 `Shift+数字行`（`!@#$%^&*()_+`）快速切换并自定义快捷键。
- **三语界面 + 帮助面板**：中文 / English / 日本語，首次进入自动弹出帮助。

### 快速开始

```bash
python server.py
# 浏览器打开 http://localhost:8080/Chalax.html
```

- 重新生成数据：`python server.py --regen`
- 键盘冲突测试工具：[keyboard-test.html](keyboard-test.html)
- 注意：音频引擎 Tone.js 走 CDN，需联网；采样文件位于本地 `data/sound/`。

## English

**Chalax** is a build-free, front-end-only web microtonal / overtone grid instrument based on **LΛMPLIGHT's Shasavistic music theory**. It visualizes "dimension = prime overtone" as a two-dimensional just-intonation lattice: each cell is a note. Click, drag, or press keys to play, and optionally overlay interval differences (comma ratio + cents).

### Features

- **2D just-intonation lattice**: choose one dimension per axis (1D–5D map to primes 2, 3, 5, 7, 11); a cell's pitch ratio = `horizontalPrime^x × verticalPrime^y` (octave-reduced).
- **Multiple ways to play**: click, drag, keyboard (the middle `asdf` row is the root row); hold a key for sustained sound.
- **Difference display**: each note's interval difference to every dimension's overtone, shown as "comma ratio + cents", filterable by threshold and dimension.
- **6 sound sources**: a sine synth plus 5 samplers (piano, strumstick, vibraphone, concert harp, pipe organ), with adjustable release.
- **Three flash-color modes**: Difference (nearest dimension), Dimension direction (root white), Wavelength (frequency → light wavelength → color), plus a saturation slider.
- **Custom shapes (chords)**: record a set of notes relative to a root and play them with one action; switch quickly via `Shift+number row` (`!@#$%^&*()_+`) with customizable shortcuts.
- **Trilingual UI + help panel**: 中文 / English / 日本語; the help opens automatically on first visit.

### Quick start

```bash
python server.py
# open http://localhost:8080/Chalax.html
```

- Regenerate data: `python server.py --regen`
- Keyboard ghosting test tool: [keyboard-test.html](keyboard-test.html)
- Note: Tone.js is loaded from a CDN (internet required); samples live in `data/sound/`.

## 日本語

**Chalax** は、**LΛMPLIGHT の「シャサフ式」音楽理論**に基づく、ビルド不要・フロントエンドのみの Web 微分音 / 倍音グリッド楽器です。「次元 = 素数倍音」を二次元の純正律格子として可視化し、各セルが一つの音になります。クリック・ドラッグ・キーで発音でき、音差（コンマ比 + セント）を重ねて表示できます。

### 主な機能

- **二次元純正律格子**：横 / 縦に次元を一つずつ選択（1D–5D は素数 2、3、5、7、11 に対応）。セルの音高比 = `横素数^x × 縦素数^y`（オクターブ還元）。
- **多彩な演奏方法**：クリック、ドラッグ、キーボード（中央の `asdf` 行がルート行）。キー長押しで持続音。
- **音差表示**：各音から各次元の倍音への音程差を「コンマ比 + セント」で表示し、閾値と次元で絞り込み可能。
- **6 種類の音源**：正弦波シンセ + 5 種のサンプル（ピアノ、ストラムスティック、ビブラフォン、コンサートハープ、パイプオルガン）。リリース調整付き。
- **3 種の点灯色**：音差（最近の次元色）、次元方向（ルートは白）、波長（周波数 → 光の波長 → 色）。彩度スライダー付き。
- **カスタムシェイプ（和音）**：ルートに対する音の集まりを録音し、ワンアクションで演奏。`Shift+数字行`（`!@#$%^&*()_+`）で素早く切り替え、ショートカットもカスタマイズ可能。
- **3 言語 UI + ヘルプパネル**：中文 / English / 日本語。初回アクセス時にヘルプが自動で開きます。
